## 1. 项目概述

项目名称：Mavicer's Blog
项目目标：1:1 复刻 aleph-null.cc（Hexo + Redefine 主题）的视觉风格，
并在此基础上构建完整的个人博客系统，包含文章管理、用户认证、
展示页面等功能。

复刻来源：https://aleph-null.cc
GitHub 仓库：https://github.com/Mavicer/blog
本地开发地址：http://localhost:5174

### 3.2 数据流

文章数据流：
  静态 .md 文件 (src/data/posts/)
    ↓ import.meta.glob
  localStorage CMS 文章 (articlesService)
    ↓ mergePosts() 合并
  usePosts() hook
    ↓
  首页 / 文章详情页

认证数据流：
  用户输入 → auth/auth.ts (register/login)
    ↓ hash 密码 + 写 localStorage
  useAuth() hook
    ↓
  AccountDock / Admin / GalleryAdmin

主题数据流：
  themeService (时间驱动 06:00-18:00)
    ↓ subscribeEffective() 60s 轮询
  useTheme() hook
    ↓ effectiveMode
  .dark class + 背景图 + hljs 主题 + 图标

## 7. 功能模块详解

### 7.1 主题系统 (themeService.ts)

  三态：auto / light / dark
  时间判断：getHours() ∈ [6,18) → light
  订阅：subscribeEffective() 60s 轮询 + storage 跨 tab 事件
  持久化：localStorage MAVICER_THEME_MODE
  派生：effectiveMode = (mode === auto) ? resolveTimeMode() : mode

### 7.2 认证系统 (auth/)

  注册流程：
    输入 → hash(password) → 写 MAVICER_USERS → 创建 session → setUser
  登录流程：
    输入 → 查 users → 比对 hash → 创建 session → setUser
  seedOwner：
    AuthProvider mount 时检查 leon_kong 是否存在，不存在则创建
  迁移：
    旧 MAVICER_TOKEN/MAVICER_USER → 新 MAVICER_SESSION

### 7.3 文章系统 (usePosts.ts + articlesService.ts)

  数据合并优先级：
    1. localStorage CMS 文章（最新，source: "local"）
    2. 静态 .md 文件（source: "static"）
    3. 后端 API（已移除 fetch，未来重新接入）
  排序：
    date desc → sortOrder desc
  实时刷新：
    mavicer-articles-changed 自定义事件 + storage 事件

### 7.4 展示系统 (galleryService.ts)

  文件上传流程：
    <input type="file" accept="image/*"> → FileReader.readAsDataURL → dataURL
    视频：额外 extractVideoCover() → canvas seek 1s → JPEG dataURL
  存储限制：
    localStorage ~5MB，适合少量照片；大视频建议 URL 方式
  视频播放：
    YouTube：自动提取 video ID → iframe embed
    B 站：自动提取 BV 号 → iframe embed
    直链：<video> 标签

### 7.5 Markdown 渲染 (lib/markdown.ts)

  引擎：marked v14
  代码高亮：highlight.js（mac 风格窗口 + 语言标签 + traffic dots）
  数学公式：KaTeX
  TOC 提取：从 H2/H3 提取，IntersectionObserver 高亮
  图片：loading="lazy" + data-viewer 点击放大
  列表：恢复 Tailwind preflight 移除的 list-style-type

## 8. 已知问题与限制

  1. localStorage 容量限制 (~5MB)
     - 大量照片/视频上传会溢出
     - 未来：后端对象存储

  2. 认证安全性
     - 密码 hash 非加密安全（djb2 算法）
     - 无 JWT、无密码强度、无邮箱验证
     - 未来：argon2 + JWT + 邮箱验证

  3. 评论/点赞/收藏
     - UI 占位，后端离线时静默失败
     - 未来：FastAPI + WebSocket

  4. 访问统计
     - 依赖第三方 busuanzi 脚本，可能不稳定
     - 未来：自建 analytics

  5. 在线人数
     - 后端 ping 失败时显示 0
     - 未来：WebSocket / SSE

  6. 多设备同步
     - localStorage 单机数据，不同步
     - 未来：服务端会话

  7. 搜索
     - 仅前端过滤，无全文索引
     - 未来：后端 Elasticsearch

  8. SEO
     - 纯 SPA，无 SSR/SSG
     - 未来：Vite SSG 或 Next.js
