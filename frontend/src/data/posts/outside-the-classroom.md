“中国的本科教育不是濒临崩溃，而是早已崩溃。”

第一次在《上交生存手册》中读到这句话时，就感到一种莫名的震撼。
那时自己还没有真正进入大学，对本科教育的认识，大多来自网络上的评价和一些模糊的想象。
直到如今入学一个多月，才逐渐开始理解这句话背后的情绪。
当然，我并不完全认同这样绝对的判断，但至少就目前的经历而言，理想中的大学与现实之间，确实存在着不小的落差。

原本以为，进入大学意味着终于可以把精力投入自己真正感兴趣的领域，可以更加自由地探索知识，而不必再像高中那样围绕考试和分数安排生活。
然而现实似乎并不完全如此。繁杂的通识课程、形式化的活动、接踵而至的任务，依然占据着不少时间。
有些课程讲授的内容几乎毫无价值，教学方式和考核要求也常常让我感到困惑：我们究竟是在学习知识，还是在完成某种既定的流程？

当然，才入学一个月就对整个本科教育下结论，未免有些武断。
况且我现在接触的专业课程还不多，真正的学习或许才刚刚开始。
但这种困惑确实存在，也促使我开始重新思考，大学四年究竟应该怎样度过。

今天下午，我去参加了学校的招聘会。

其实一个大一新生出现在招聘会上，多少有些不合时宜。
我既没有像样的竞赛奖项，也没有论文和科研成果，甚至连专业基础课都还没学多少。
去之前也没想着真的找到实习，只是突然觉得，与其整天在学校里猜测企业需要什么样的人，不如直接去问问那些真正负责招聘的人。

第一家是做 AIGC 的公司，招聘人员很耐心地向我介绍了他们的业务和岗位。
我问她，拿到一份本科生的简历，通常会先看什么。
她的回答很直接：竞赛、论文和项目经历。
通过这些大致判断一个人的能力，再匹配相应的岗位和薪资。

聊到我自己时，我也如实介绍了目前的情况：学过一些 C 和 Python，接触过 Web 开发，做过几个小项目，也使用前沿AI工具辅助编程。
她认为我目前还主要停留在比较基础的 AI 应用层面，如果现在实习，大概只能匹配数据标注、数据清洗之类的岗位，月薪 3600 元左右。

这个数字倒没有让我失落。
毕竟才大一，我也清楚自己的水平。
只是第一次有人从企业用人的角度，对我目前的能力作出如此具体的评价，感觉还挺奇妙。
平时自己折腾出一个网站，解决几道编程题，总觉得又掌握了不少东西；但放到真实的生产环境里，这些能力似乎还远远不够。
能把程序跑起来，与能够承担实际的工程任务，终究是两回事。

后来，我又斗胆去了华为的展位。

招聘人员看到我是大一新生，显得有些好奇，问我为什么这么早就来了解招聘。
我解释说，自己并不是来找工作的，而是希望尽早了解市场真正需要什么样的人才，以此作为未来学习规划的参考。
比起等到大三大四才开始考虑就业，我更希望在本科阶段就有意识地培养相关能力。

没想到聊得很愉快。

她同样提到了竞赛、科研、论文和 GitHub 项目的重要性，也特别强调了对 GPT、Claude 等先进 AI 工具的熟练使用。
我们还聊到了一个很有意思的问题：既然 AI 已经能够完成越来越多的编程任务，为什么企业仍然需要大量工程师？

其中一个例子是高并发场景下的系统稳定性。
让 AI 写出一段能够运行的代码或许并不困难，但当系统需要同时服务成千上万的用户，涉及数据库、缓存、并发控制和各种异常情况时，问题就远没有那么简单了。
AI 可以参与解决这些问题，但真正理解系统的运行机制，判断方案是否可靠，并对结果负责，仍然需要相当扎实的专业能力。

这让我想起自己之前做过的一些项目。
借助 AI Coding 工具，我确实可以在很短的时间内搭建出一个看起来还算完整的网站，但如果继续追问底层原理、系统设计和性能优化，我未必都能解释清楚。
工具大大降低了实现一个想法的门槛，却没有自动填补我在基础知识和工程经验上的欠缺。

第三家是一家面向企业客户提供 AI 解决方案的公司。
他们对实际项目经验和 GitHub 的重视程度同样很高，甚至提到新员工需要经过长达六个月的培训。
几家企业还都不约而同地谈到了 Java 全栈能力。这倒让我有些意外。
原以为人工智能相关岗位会更多地强调模型和算法，没想到企业真正落地 AI 应用时，依然离不开传统的软件工程能力。

值得一提的是，我向三家企业都提出了同一个问题：
为什么你们似乎并不怎么关注本科生的绩点、综测和专业排名？

得到的回答大同小异。
他们认为，目前本科教育中的不少内容与企业的实际需求存在脱节，相比单纯的成绩，更希望通过项目、竞赛和科研经历来了解一个人的学习能力和解决问题的能力。

这与我最近对大学学习的困惑不谋而合。

过去十几年，我们似乎已经习惯了用成绩衡量学习成果。
尤其是高中阶段，目标明确，评价标准也相对统一。
只要成绩足够好，就有机会进入更好的大学。
于是大家心照不宣地接受了这套规则，把大量时间投入到分数的竞争中。

但进入大学之后，情况似乎变了。
成绩依然重要，却不再是唯一的评价标准。
一个人可以拥有很高的绩点，却缺乏独立完成项目的能力；
也可以在课堂之外积累大量实践经验，但成绩并不十分突出。
学校认可的优秀，与企业需要的优秀，并不总是完全重合。

当然，这不意味着绩点和排名没有价值。
我现在反而觉得，它们在一定程度上仍然能够反映一个人的基础能力和学习态度。
尤其对于尚未确定未来是否深造的我而言，保留一个不错的成绩，也是在给自己留下更多选择的余地。
数学、数据结构、计算机系统这些基础知识，本身就值得认真学习，不能因为短期内看不到用途便轻易忽视。

只是没有必要继续沿用高中时期的思维，为了把已经不错的成绩再提高几分，不惜牺牲大量本可以用于探索和实践的时间。
特别是在边际收益越来越低的时候，这样的投入是否值得，确实需要重新考虑。

仔细想想，我们似乎太容易陷入一种惯性。
高中时争排名、争分数，进入大学又开始争绩点、争综测、争奖项、争各种头衔。
好像总要在某个评价体系中证明自己，才能获得一点安心。
但这些竞争究竟是为了什么呢？

如果一场竞赛能够让我接触真正感兴趣的技术，认识优秀的伙伴，即使最终没有获奖，我也愿意投入时间。
可如果只是为了给简历增加一行字，去参加一项自己毫无兴趣的活动，或许就没有那么大的必要。
科研也是如此，前两天与老师和研究生学长交流时，我第一次接触到了真实的科研项目，也逐渐意识到科研并不像想象中那么简单。
一个具体的问题背后，可能是大量枯燥的数据处理、实验和反复验证。
相比于急着给自己贴上“科研经历”的标签，我更希望先弄清楚自己究竟对什么感兴趣，又愿意为此投入多少精力。

说到底，竞赛、论文、绩点乃至学历，本来都应该是帮助我们实现目标的工具，而不是目标本身。

不过，今天招聘会上的经历也让我意识到，自己或许还需要警惕另一种倾向：不能因为发现企业重视项目，就立刻把过去对分数的焦虑，转移到 GitHub 仓库数量、竞赛奖项和实习经历上。

如果以前是为了考试而学习，以后却变成为了简历而开发，那似乎也没有从根本上改变什么。

我还是希望自己能够真正学会一些东西，而不只是为了满足某张招聘启事上的要求。
相比于完成多少个项目，我更在意自己能否逐渐理解其中的原理，能否独立解决越来越复杂的问题。
至少在现阶段，保持好奇心和学习的主动性，可能比急于确定未来的职业方向更加重要。

写到这里，再回头看《上交生存手册》中的那句评价，说到底，只是认真完成本科教育，远不够成为一个有竞争力的人。
大学能够提供基础、资源和机会，却未必能替每个人找到适合自己的道路。
与其一味抱怨教育体系的不足，或者干脆否定它的价值，我更愿意在现有条件下主动寻找自己真正需要的东西。
毕竟，我既不想成为一个只会考试的人，也不想成为一个连基础知识都没有掌握、却自认为不受传统教育束缚的人。

或许我真正不满的，并不是大学教育本身，而是某些形式化的要求占据了本该用于自由探索的时间，以及我们太容易将评价体系中的成功，误认为成长的全部。
当然，说起来容易，真正做到恐怕没有那么简单。
有时候绩点就是决定某个机会能否获得的门槛，有些暂时看不到用途的课程也确实需要认真完成。
未来还会有更多不得不面对的现实限制，不可能所有事情都由着自己的兴趣来。
而且，我也需要时常提醒自己，不要把“不愿意参与竞争”当成逃避困难的借口。
有些事情不想做，是因为经过思考，觉得不值得投入时间；有些事情不想做，可能仅仅是因为它太难、太枯燥，或者自己暂时做不好。

这两者之间的区别，并不总是那么容易判断。

我想要的大学生活，大概是在认真完成必要学业的同时，拥有足够的自由去接触真实的世界。
可以为了一个感兴趣的项目折腾很久，也可以主动去找老师、学长和企业交流；可以认真研究一道数学题，也可以在发现某个方向并不适合自己之后坦然放弃。
不必过早为未来作出不可更改的决定，也不必为了追逐某种标准答案，把所有时间安排得满满当当。

我知道自己现在的想法还不成熟，很多判断也只是基于有限的经历。
也许等真正学完专业课程、经历过实习和求职，再回头看今天写下的这些东西，会有完全不同的感受。
但这也没什么不好。
大学本来就应该是一个不断认识世界，也不断修正自己想法的过程。
何况，生活中还有很多事情，是我不愿意用绩点、简历或者未来收入来衡量的。
毕竟，我还有喜欢弹的钢琴曲，想拍的照片，想去的地方，它们不需要被包装成综合素质，不需要写进简历，更没有必要用未来能带来多少收益来衡量。

大学四年当然应该努力，也应该为未来做好准备。
但如果四年里所做的一切，都只是为了毕业时得到一份更漂亮的简历，那未免有些可惜。

今天下午走出招聘会时，我对未来究竟要做什么，依然没有一个明确的答案。
但至少，我比昨天更清楚企业在寻找什么样的人，也更清楚自己还有哪些不足。

这就已经是不错的收获了。

至于接下来四年要怎么走，我想不必急着把每一步都规划得十分精确。
认真学好值得学的知识，尝试真正感兴趣的事情，多看看课堂之外的世界，尽可能保留选择的余地。

也别忘了好好生活。

毕竟，大学不应该只是另一场漫长的考试。
