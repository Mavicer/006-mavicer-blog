那是一个月黑风高的夜晚，雨丝淅淅沥沥地落在窗沿，6401 教室里，近三百人正敲击着键盘，与眼前的题目展开殊死搏斗。

第一题两分钟写完源码，自信提交，0 分。怀疑溢出，换 long long，0 分；换 double，还是 0 分。冷汗直冒，最后发现 printf 忘改成 %lf…十五分钟过去，才做第二题。

第二题一眼二维数组，思路秒出，却忘了语法，又没有 AI 帮我 debug，索性改用流式处理，险险拿下…此时手已经冰凉…

不过，回头看这段经历，最值得记录的倒不是做出了多少题目，而是一个我已经习以为常的操作。

一个月下来，大学 C 语言的知识七七八八啃了大半，进度比预想中快了不少，也算是提前体验了一遍期末的考前突击。

AI 用来答疑，确实相当方便。学到指针、函数传参时，遇到看不懂的地方可以直接提问。如果解释太抽象，就让它换个形象的例子；还没听懂，继续追问。以前可能要翻好几本教科书才能弄明白的问题，现在几轮对话基本就能解决。

尤其是 C 语言这种细节比较多的语言，AI 的即时反馈能省下不少查资料的时间。但用久了就会发现，AI 有一个相当隐蔽的副作用：它不仅能帮人理解错误，还很容易让人失去自己找错误的耐心。

比如在 OJ 上写完一道题，提交之后喜提 Wrong Answer。正常来说，接下来应该检查输入输出、数组边界、循环条件，再构造几组测试数据，看看程序到底在哪里出了问题。实在找不到，还可以打印中间变量（这招真有用），一步步追踪执行过程。

现在就简单多了，复制题面，粘贴代码，发给 AI。几秒钟后，模型就能指出第几行写错了，顺便附上一份修改后的代码。修完重新提交，100 Accepted，收工。

最麻烦的是，这种做法甚至很难让人产生什么负罪感。毕竟算法是自己想的，代码也是自己敲的，只是最后找不到 Bug，让 AI 帮忙检查一下而已。比起直接复制 AI 生成的完整程序，这种操作看起来实在太合理了。但偏偏就是这种理所当然的操作，最容易让调试能力慢慢退化。

C 语言里有不少 Bug，属于看一眼就觉得没问题，实际运行起来却怎么都不对的类型。
例如：

```c
int a = 5, b = 2;

double x = (double)(a / b);  // 2.0
double y = (double)a / b;    // 2.5
```

两行代码只差一对括号，结果却完全不同。
第一行先进行整数除法，得到 2，再转换成 double；第二行先把 a 转成 double，最后得到 2.5。

输入时也有讲究：

```c
scanf("%1000s", str);
```

这里不需要加 &，因为数组名在这个表达式中会转换为首元素的地址，但 %s 遇到空格、换行或制表符就会停止读取，这时就需要考虑使用：

```c
fgets(str, sizeof(str), stdin);
```

当然，fgets() 还可能保留换行符，又是另一个值得留意的小坑。

还有更隐蔽的：if 和 while 里把 == 写成 =，把 || 和 && 弄混；比较最大最小值时忘记给 min、max 赋初值；for 循环的 i 忘了初始化。这些错误单看都低级，混在几十行代码里却非常难找。

这些知识点单独拿出来，可能一眼就能看出来。但当它们混在几十行代码里时，找出问题往往比理解问题更费时间，而 AI 恰好擅长跳过这个过程。它可以直接告诉你哪一行有问题，却不能自动把寻找问题的经验转移到你身上，久而久之，无异于自废武功。

更有意思的是，OJ 的通过记录还会制造一种进步的错觉：题目是自己做的，代码也确实通过了测试，看起来掌握得相当不错。但如果每次出现 Wrong Answer，都要靠 AI 才能找到原因，那么真正受到训练的，恐怕只有纸上谈兵的能力。

一行代码查上半天，效率看起来远不如直接问 AI，但回过头想，Debug 本身就是编程的一部分。如果连寻找错误的过程都省略了，所谓的高效率，其实更像是在自欺欺人。

在瞬息万变的 RoboMaster 赛场上，如果机器人突然趴窝了，留给队员排查故障的时间可能只有短短几分钟。究竟是通信出了问题，还是程序逻辑存在漏洞？这时候，难道还要将源码复制给 AI，敲下一大串 prompt，祈求 AI 能猜到机魂不悦的原因？

更进一步讲，既然每个人都可以简单地用自然语言让 AI 生成一段代码，那公司凭什么会选择你。实际项目中，快速分析需求并定位问题的技术，才是如今全民 vibing 时代本科生更应当追求的工程能力。

AI 固然可以缩短学习的时间，却不能代替积累解决问题的经验。那些看似低效的 Debug 过程，恰恰是在训练这种能力。代码能跑起来是一回事，知道它为什么能跑、为什么跑不起来，又是另一回事。

最后，如果你也想尝试自学 C 语言，我比较推荐《C Primer Plus》作为入门教材，配合我一直在用的 [Sky Walker OJ](https://www.skywalker-rm.online) 进行练习，题库里有 600 多道题，够喝好几壶的😋
